# ShopOps Documentation

- `architecture/`: High-level system design, database boundaries, and event topology.
- `adr/`: Architecture Decision Records (ADR-001 through ADR-012).
- `runbooks/`: Operational runbooks for incident remediation.
- `incidents/`: Incident logs, postmortems, and root-cause analyses.
- `diagrams/`: Mermaid architecture diagrams.
